# CandiClie

A React/Vite eyewear site branded candiclie, with a responsive header, seven locally hosted hero slides, featured selections of three larger product cards, glasses, contact lens and accessory catalogues, an unbranded Signature Edit campaign, five top categories, the CandiClie index and journal, a full cart page, and a responsive footer. The desktop campaign fills the browser width, including screens wider than 1920px.

## Run

Requires Node.js 22.12 or newer.

```powershell
npm install
npm run dev
```

Open the Local URL printed by Vite, normally http://127.0.0.1:5173/.

```powershell
npm run build
npm run preview
```

## Eye test booking preview

`/book-eye-test` opens the CandiClie eye-test page, with an original photographic hero, four-step booking preview, visit summary, preparation guide and six disclosure questions. Header and footer links open this page; `/book-an-eye-test`, `/eye-test` and `/store-locator?appointment=true` also work. The booking section supports direct entry at `#book-eye-test`.

The directory has 21 illustrative locations across 10 cities. Choose a city directly or search by city, area, store name or PIN prefix. Results update while typing: `5` matches areas in Bengaluru and Hyderabad, `56` selects Bengaluru automatically, and `560001` narrows to MG Road. A city is inferred only when all matching entries belong to it. Backspacing, clearing an automatic selection and direct city changes handle conflicting filters. Search runs locally and does not calculate distance or invent nearby stores. Four cards appear per page, with working pagination and empty-result recovery.

Each store card has a locally hosted representative optical-store photograph, address, city, state and PIN. Show on map focuses its area in the embedded map; Open maps opens a Google Maps area search. Map pins follow all matching results, including cards on later pages. Selecting a pin by pointer, Enter or Space shows its details below the map; View store card moves to the correct page and focuses its heading. Show all results refits the map. Area positions are approximate, not verified branch entrances, and the photographs are representative, not photographs of the named branches.

The map uses [Leaflet 1.9.4](https://leafletjs.com/), installed with the root package lockfile. Its JavaScript loads when the map approaches the viewport; it is excluded from the initial homepage bundle. Map controls and markers use the neutral interface palette. One-finger phone swipes scroll the page, while pinch and zoom controls adjust the map. ResizeObserver handles orientation and container changes. Location details appear below the map so they do not obscure pins or controls. If background tiles fail, the pins and external area links remain available. The page fetches standard [OpenStreetMap tiles](https://operations.osmfoundation.org/policies/tiles/) only for interactive viewing, with visible attribution. `VITE_STORE_MAP_TILES` can configure a compatible OSM-derived tile URL. Area coordinates were checked once using [OpenStreetMap area lookups](https://operations.osmfoundation.org/policies/nominatim/), with a descriptive User-Agent, sequential requests below one per second and cached responses; the application makes no runtime geocoding requests. Original lookup records and unused research data remain ignored under `reference/eye-test/map-data`. Coordinate/map data is credited to [OpenStreetMap contributors](https://www.openstreetmap.org/copyright).

Book appointment opens date/time selection for the chosen store. The flow then collects contact details and visit focus, allows editing and review, and shows a completion screen. Changing stores clears the previous date/time; reselecting the same store keeps them. Dates use Asia/Kolkata and a 30-day range. Example times must be more than an hour ahead and are checked again on completion. Mobile numbers use a valid 10-digit Indian format; email is optional. Native radio controls support keyboard date/time selection, step changes move focus to headings, and field errors identify their controls. Refreshing or leaving clears the entered details. No booking details are persisted or transmitted; tile requests contain geographic tile coordinates only.

This is a preview with no booking backend or verified CandiClie store directory. The booking section identifies the illustrative locations and times. Store cards and booking screens use plain labels; addresses contain street or area names without invented unit numbers. Completing the flow does not reserve a visit, send email/SMS or take payment. Real stores, services, pricing, hours and appointment confirmations must be connected before live bookings launch.
