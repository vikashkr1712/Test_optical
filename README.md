# CandiClie

A React/Vite eyewear site branded candiclie, with a responsive header, eight locally hosted hero slides, featured selections of three larger product cards, a browsable glasses catalogue for men, women and kids, an unbranded Signature Edit campaign, five top categories, the CandiClie index and journal, a full cart page, and a responsive footer. The desktop campaign fills the browser width, including screens wider than 1920px.

## Run

Requires Node.js 22.12 or newer.

```powershell
npm install
npm run dev
```

Open the Local URL printed by Vite, normally http://127.0.0.1:5173/.

```powershell
npm run build
npm run preview
```

The production output is in `dist/`. All header and hero navigation stays on this app's own origin. Header search opens a responsive panel that searches the complete 133-frame catalogue by brand, model, colour, type, shape and audience, with recent searches. Product previews and search results support adding to the cart and saving frames. The bag icon opens `/cart`, with a spacious empty state, Continue shopping and Check my orders actions. Filled carts include quantity controls (up to ten per frame), removal and indicative subtotals. Continue shopping opens the glasses catalogue. Cart selections, saved frames and search history persist in browser-local storage; unavailable storage falls back to the current visit. Profile opens a centered CandiClie sign-in modal with sign-in/create-account modes and email/mobile validation. Check my orders opens the same modal with order-specific guidance. Authentication, OTP delivery, order history and checkout are not connected; the form states that no code has been sent and does not send or store contact details. Runtime media loads from local files; source URLs and download metadata are retained in local reference records.

For Vercel, import the app at the repository root (`./`). The root `vercel.json` selects Vite, builds with `npm run build`, publishes `dist`, and rewrites application URLs to `index.html` so navigation and direct reloads do not return Vercel's 404 page. `/cart` renders the cart. `/eyewear`, `/eyewear/eyeglasses`, `/eyewear/sunglasses` and `/eyewear/new-in` render glasses collections; appending `/men`, `/women` or `/kids` selects the audience. Unimplemented destination paths continue to render the homepage.

The Glasses menu keeps the existing navbar layout, styles and disclosure behavior. Its ten submenu entries and Explore Glasses action now open real collections inspired by GKB Opticals' category flow. Collection tabs switch between all glasses, eyeglasses, sunglasses and the new edit; audience chips retain the selected frame type. A responsive product grid includes local front/angle photographs, frame details, reference prices and saved-frame hearts. The Sort & filter drawer supports brand, shape, colour, rim style and price, with multi-select within groups, combined filters across groups, five sorting options, removable filter chips and clear actions. Search, filters, sorting and the saved-only view are reflected in the URL and survive refresh and browser history. Empty results have recovery actions. Product previews show available image angles, shape, rim style and audience and connect to the existing browser-local cart. The 127 additional reference frames use about 3.1 MiB of responsive WebP images; original downloads and provenance remain locally under `reference/glasses`. No dependencies or external runtime requests were added.

The catalogue starts with up to 24 frames and automatically appends another batch when the visitor scrolls near the end. Each matching frame appears before the selection repeats; recommended browsing shuffles subsequent passes and avoids adjacent duplicates when multiple frames match. Explicit sorting retains the selected order on each pass. Every repeat refers to the same product, so saved state and cart actions stay consistent. The saved-only view lists each saved frame once. New batches wait for their product photographs; a twelve-spoke grey loading animation and Loading label appear only while a batch is pending. The loading area has no idle messages, counters, buttons or footer shortcuts. The footer stays below the catalogue, without a lifestyle image section. Failed batches can retry on subsequent scrolling or when connectivity returns, with a delay between attempts. Keyboard scrolling and browsers without scroll observers use the same automatic loading behavior. Changing the category or filters discards pending batches from the previous selection. Offscreen card rendering is deferred for longer browsing sessions. Reduced-motion preferences keep the loading graphic still.

The hero uses 600ms eased transitions with a forward loop. Both videos play to their actual end before advancing; every image stays visible for five seconds on desktop and mobile. Only the settled, visible video plays; upcoming media is prepared without playing hidden videos. Manual video selection and a new carousel cycle restart playback from the beginning, while returning from an offscreen or hidden page resumes the current video. Image timers pause during keyboard focus, dragging and hidden/offscreen states; reduced-motion preferences disable automatic playback and progression. The first slide is a 20-second, 1920×720 / 60fps render of the same fifteen supplied campaign images. Steady framing removes the source clip's small back-and-forth pan/zoom shifts, and 400ms eased cross-dissolves smooth the scene changes. Its existing soundtrack is copied without reencoding, including the ending fade. Fifteen three-line captions retain their scene timings, synchronized with presented video frames, and fade in place without an upward bounce. White desktop captions sit over a consistent dark gradient; the first campaign's portrait layout uses dark captions below the full picture on white. The third slide keeps its original video without a text overlay or caption scrim. Play/pause and mute/unmute controls are available, with muted autoplay when browser policy requires it. Original reference media and the earlier runtime video are retained locally.

The six still-image slides following the first campaign use newly selected Unsplash eyewear photographs with local desktop/mobile WebP variants. Large captions sit on solid white or dark green panels, beside the photograph on desktop and below it on portrait screens. The light hero panels, collection sections, navigation panels, previews and search surfaces use white in place of cream. Buttons scroll to existing homepage sections. Distant photos remain deferred; only the current and upcoming media are prepared. Taps between pagination markers remain neutral, including when a touch browser retargets the compatibility click to a nearby button. Previous promotional banners and downloaded originals are retained locally and excluded from Git. Google Images showed a traffic check during discovery, so selection continued through the available web image search.

The CandiClie Edit uses a restrained serif heading and keyboard-accessible Signature Picks / New In tabs. Product card colours, images, previews and shopping behavior are preserved. Men's, women's, kids' and eyeglasses cards open their corresponding catalogue collections; the fashion card retains its collection preview. The Signature Edit reuses an existing unbranded eyewear photo; the retired branded banner remains locally and is excluded from Git. Homepage product prices are reference observations from 22 October 2026; the additional catalogue references were observed on 25 October 2026. Previews do not implement inventory or checkout, and reference-site promotions are not reproduced as live offers.

The eight navbar labels are Glasses, Contact Lenses, Care & Accessories, Designer Brands, Our Story, Special Offers, Seasonal Edit and Gift Cards. Each opens an existing detail menu: desktop disclosure panels and mobile accordions. Glasses options open the catalogue; other submenu options retain their relevant on-page previews with links to homepage sections. Menus support keyboard activation, ArrowDown, Escape, outside-click dismissal, and focus restoration. Contact lens, accessory, offer and gift card details explain the current browsing availability without adding checkout or other pages. Brand names are shared between the directory and navigation; menus add no new image files or dependencies.

The CandiClie index uses an eight-card horizontal rail with editable sample names, including Aurel, Northline, and CandiClie Studio. The three journal cards reuse Lenskart's reference photographs temporarily. These display names are creative placeholders, not claims of brand partnerships. Brand and style previews stay on the homepage.

The CandiClie journal opens with an enlarged centre portrait and smaller side images. Clicking either side image brings it into the same centre size; arrows, touch swipes and keyboard navigation support looping through all three stories. Hover adds a gentle zoom within the fixed image area and reveals an Explore arrow. Heading fonts are served locally, and reduced-motion preferences disable animated movement.

Two compact sections follow the journal: Why Choose CandiClie and Lens & Care Guide. The guide's four topics and Learn more button open accessible on-page details using the existing preview dialog. No new routes, dependencies or services are added.

Why Choose CandiClie cards have a small hover lift, a soft shadow, filled icons and an expanding accent line. Hover motion is limited to devices with a precise pointer and is disabled for reduced motion. The utility header strip and footer use black backgrounds with neutral text accents. The campaign video uses a lighter, gradual overlay to support readable captions without heavily darkening the footage.

The footer combines dark styling and grouped navigation inspired by premium eyewear retailers, with in-page shopping/style/privacy help and a keyboard-accessible back-to-top control. Its links target existing sections. It adds no image downloads, third-party scripts, or new dependencies.

Typography uses 14–16px for supporting copy and actions, 18–19px for product models and prices, and stronger weights for headings and important links. Small decorative indices and collection labels remain subordinate. Responsive checks cover seven widths from 320px to 2560px; browser scripts and results remain local.

Collection and editorial imagery is locally hosted as responsive WebP variants, loaded lazily with reserved layout space. A device requests only the applicable variants; community photos are not enlarged beyond the source resolution. A preloaded 40 KB first-frame poster keeps the hero visible while its video loads. Hero videos and autoplay pause when the hero leaves the viewport; distant hero images load only when active or next. No new JavaScript dependencies or third-party runtime requests are added.

## Deployment files

The repository contains application source, used images/fonts/videos in `public`, the root package files, build/deployment configuration, and this README. Lifestyle photos include Unsplash imagery; editorial reference photos are temporary. Original source URLs, inventories, hashes, and download metadata remain locally under `reference`.

Generated screenshots, source records, project notes, unused media, browser tests and inspection tools, build output, and dependencies are kept locally and excluded from Git and deployment.

Push changes to GitHub only when explicitly requested by the project owner.
